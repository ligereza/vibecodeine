# RD isolated prototypes

These files are preserved as non-operational research and design prototypes
from the isolated RD work. They are not mounted by `/api/rd-db`, `/portafolio/`
or the standalone Plano/Rider builds.

- The matrix and POST files are visual/semantic experiments.
- The reagent audit and relation reports are candidate research, not canonical
  claims.
- The cover SVG/PNG is a visual reference and is not added to the production
  asset catalog.

Promotion requires an explicit RD human decision and an existing route or
canonical source. Preserving a prototype here must not be read as approval of
its scientific interpretation or as a request to build a parallel UI.
