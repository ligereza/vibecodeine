# Brief visual semántico de POST Chemsex

Este brief traduce la especificación textual a reglas para el motor SVG. No genera ilustraciones ni modifica el texto de RD.

## Regla del sistema

La forma representa relaciones semánticas: contexto, entidad, interacción, cuidado, límite y agencia. El movimiento debe expresar cambio de relación, no sólo desplazamiento decorativo.

## s01_cover

Rol: threshold_and_invitation

Vector: community, care, conversation, non_stigmatizing_entry

Forma primaria: open_frame_with_two_or_more_elements_that_can_approach_without_colliding

Animación: A closed or quiet field opens into a shared space; no warning icon appears before the invitation.

No hacer: do_not_start_with_panic; do_not_use_medical_cross_as_primary_symbol; do_not_add_unprovided_claims

## s02_definition_and_harm_reduction

Rol: definition_to_multiple_care_dimensions

Vector: sexual_context, psychoactive_substances, altered_experience, multiple_forms_of_care

Forma primaria: one_shared_field_that_branches_into_three_non_hierarchical_care_paths

Animación: A single context separates into physical, infection-related, and mental-health care dimensions without implying that one is the only cause.

No hacer: do_not_draw_prevention_as_total_control; do_not_collapse_care_into_one_warning_symbol

## s03_chile_context_and_substances

Rol: local_context_and_entity_field

Vector: Chile, private_party, public_space, apps, substance_inventory

Forma primaria: map_like_context_field_with_distinct_substance_nodes

Animación: Context zones appear first; substance nodes enter as a heterogeneous field, not as a single visual category.

No hacer: do_not_assign_risk_color_only_from_presence; do_not_make_all_substances_look_identical; do_not_imply_all_contexts_are_equivalent

## s04_general_risks

Rol: four_risk_dimensions_without_totalizing

Vector: drug_risk, cardiovascular_context, sexual_health, mental_health

Forma primaria: four_intersecting_but_non-identical_fields

Animación: Four dimensions enter from different directions and overlap only at a shared context center; no single dimension dominates the whole frame.

No hacer: do_not_turn_risk_map_into_a_probability_chart; do_not_invent_numbers; do_not_make_viagra_the_only_visual_subject

## s05_care_actions

Rol: distributed_practical_care

Vector: hydration, non_sharing, information, testing, PrEP, PEP, doxyPEP, consent, rapid_care

Forma primaria: several_supporting_actions_around_a_shared_center

Animación: Each action becomes a stable support around the center; the system must not show a single action as the universal solution.

No hacer: do_not_turn_actions_into_commands_beyond_source_text; do_not_animate_medical_access_as_guaranteed; do_not_hide_consent_inside_secondary_text

## s06_riskier_interactions

Rol: relational_warning_map

Vector: combination, interaction, depressor, cardiovascular, pressure, antiretroviral_context, professional_query

Forma primaria: separate_entity_nodes_connected_by_visible_interaction_edges

Animación: The interaction is a change in relation: nodes approach, influence, or destabilize a shared field. Do not animate substances as if they transform into one another.

No hacer: do_not_draw_mixture_as_new_substance; do_not_use_color_as_numeric_risk_score; do_not_upgrade_claim_only_cards_to_scientific_relations

## s07_conclusion

Rol: agency_and_community_return

Vector: decision, community_information, anti_stigma, professional_contact, trusted_network

Forma primaria: field_returns_to_open_collective_composition

Animación: The visual field reopens and distributes agency to the viewer; it ends with an invitation, not a final alarm state.

No hacer: do_not_end_with_a_punitive_symbol; do_not_promote_the_organization_as_medical_authority; do_not_add_dosage_advice
