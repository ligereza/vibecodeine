# Quantified Self y repositorios

Fuente inicial: https://github.com/topics/quantified-self

Firecrawl capturó la página temática, que declaraba 481 repositorios públicos. GitHub ordena y etiqueta el inventario; por eso es una fuente de descubrimiento, no una taxonomía neutral.

## Referencias conceptuales

- [ActivityWatch](https://github.com/ActivityWatch/activitywatch): actividad y tiempo, con orientación de privacidad.
- [HPI](https://github.com/karlicoss/HPI): acceso unificado a rastros digitales personales.
- [Memacs](https://github.com/novoid/Memacs): representación temporal de la vida digital.
- [chronicle-etl](https://github.com/chronicle-app/chronicle-etl): extracción, ETL y archivo personal.
- [Obsidian Tracker](https://github.com/pyrochlore/obsidian-tracker): convierte notas en ocurrencias y números.
- [qs_ledger](https://github.com/markwk/qs_ledger): agregación y análisis de datos personales.

## Traducción para ONG

La idea útil no es vigilar personas, sino producir una radiografía del archivo institucional:

- duplicados y versiones contradictorias;
- antigüedad y falta de responsable;
- tiempo para encontrar información;
- procesos dependientes de una sola persona;
- vocabulario inconsistente;
- carpetas que funcionan como depósitos, no como sistemas.

El resultado sería un mapa de fricción, no una puntuación de productividad.
