# Revisiones de proyectos para ONG

## NGOWorld

Fuente: https://github.com/ngoworldcommunity/NGOWorld

Plataforma para conectar ONG, organizaciones benéficas y personas interesadas en colaborar. Firecrawl detectó licencia MIT, registro de organizaciones, conexión y colaboración.

**Evaluación:** sirve como referencia para red, onboarding y contribuciones estructuradas. No hay evidencia suficiente de archivo institucional, curaduría documental, trazabilidad, control de versiones, almacenamiento o seguridad. Su relevancia documental es baja.

## Houdini

Fuente: https://github.com/houdiniproject/houdini

Infraestructura libre de fundraising para ONG y organizaciones sin fines de lucro. Incluye campañas, crowdfunding, donaciones, eventos, perfiles, pagos, métricas, CRM, cuentas y donaciones recurrentes. La captura identifica PostgreSQL y Ruby on Rails.

**Evaluación:** relevancia operativa alta; relevancia documental baja o indirecta. Es útil para entender qué datos y procesos debe gobernar una ONG —transacciones, cuentas y donaciones— antes de preparar su documentación de privacidad. No hay evidencia suficiente sobre seguridad o licencia en la captura, por lo que no sería un primer piloto para datos reales.
