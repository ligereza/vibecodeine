# Postulaciones prioritarias 2026

Este directorio concentra los tres concursos que la dirección está siguiendo:

1. **Fondart Nacional - Investigación 2027**: proyecto *Jardines interpretativos*.
2. **Fondart Regional - Creación Artística 2027**: proyecto *IRIS: Mesa de Montaje*.
3. **Becas Fundación Ama Amoedo 2026 - categoría Artistas**: postulación independiente.

Cada carpeta usa la misma lógica:

- `01_BASE_ORIGINAL...pdf`: base conservada sin editar, cuando fue posible verificar el archivo.
- `02_...`: proyecto, encaje e investigación relacionada.
- `03_REQUISITOS_CONDICIONES_ALERTAS.md`: requisitos operativos, condiciones, criterios y preocupaciones.
- `04_FICHA_CONVOCATORIA.json`: ficha estructurada existente, con su procedencia y estado de verificación.
