## Functional defects found before remediation

### P0 — visible broken capability (resolved)

1. Codex was advertised as a main tab while its existing upstream unit was
   inactive. The runtime was found at `/home/mak/codex/interfaz_codex.py`,
   started and enabled; the broken state is resolved.

### P1 — broken assets and misleading 200 responses (resolved)

2. `/static/iskvw/editor` returns the editor HTML, but its relative
   `mesa_montaje.js` request becomes `/static/iskvw/mesa_montaje.js`. That path
   returns the Hub root HTML with status 200 instead of JavaScript. The browser
   records `SyntaxError: Unexpected token '<'`. The editor therefore appears
   present while its script is not actually served.

3. The legacy Plano page `/static/rd/plano` links to
   `../../context/plano_demo.html`. `/context/plano_demo.html` currently falls
   through to the Hub root HTML rather than serving the referenced demo. The
   legacy editor itself renders, but its recommended replacement link is not a
   valid route.

4. Unknown non-API paths fall back to the Hub root with HTTP 200. This masks
   missing CSS, JavaScript and HTML assets. Static asset namespaces need a
   404 contract or explicit serving rule before future UI claims can be trusted.

### P2 — confusing or stale surfaces (partially resolved)

5. `research` and `laboratorio` are both functional but represent two research
   surfaces: the older workflow canvas on `:8890` and the newer persistent job
   registry on `:8900`. They need an explicit distinction or one should become
   the default entry for investigations.

6. `genesis` contained historical architecture statements (including the old
   department/port topology). It is now classified as a historical archive
   under an orientation page; it no longer opens as a bare document.

7. `relevo` now falls back to the canonical `context/LAST_HANDOFF.md` when the
   legacy source file is absent, so it is a usable continuity surface.

## Remediation result

Applied to the canonical Hub and validated in foreground:

    `mak-codex.service` started and enabled; `/codex/` -> HTTP 200;
    `/static/iskvw/mesa_montaje.js` -> HTTP 200, `text/javascript`;
    independent ISKVW editor -> 22 controls, zero browser console errors;
    `/context/plano_demo.html` -> HTTP 200, 76 controls, zero browser errors;
    Plano legacy link now targets the served absolute demo route;
    missing `/static/*` and `/context/*` assets -> HTTP 404;
    department aliases -> HTTP 301 to `iskvw` and `cultura`;
    `/genesis` -> orientation/archive page;
    `/relevo` -> current handoff source;
    `py_compile` and focused Hub/ISKVW/entrypoint tests -> PASS.

The remaining architectural follow-up is to make the distinction between the
legacy Research canvas and the persistent Research Garden explicit. Both are
currently functional and are intentionally not removed in this repair.
