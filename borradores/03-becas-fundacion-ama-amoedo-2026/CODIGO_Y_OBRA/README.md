# Codigo y obra - Ama Amoedo

Este directorio conserva los materiales que pueden convertirse en portfolio,
anexo o evidencia de proceso para una propuesta artística. No todo lo que se
encuentra aquí debe enviarse.

- `tapiz/`: proyecto VibeCode completo, documentación, piezas SVG, wrappers y
  biblioteca de motivos.
- `borradura_ascii/`: código de borradura, tapiz textual, reporte y dossier.

La selección de portfolio debe hacerse desde la obra y su documentación,
revisando autoría, derechos, epígrafes, enlaces públicos y la relación entre el
material y una propuesta única. El código es un medio o registro de proceso,
no automáticamente la obra que se presenta.
