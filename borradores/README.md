# Borradores de postulaciones

Paquete de trabajo de la rama `MAK`, actualizado el 2026-09-05. Reune textos,
estructuras, investigacion, anexos, codigo, datos y obras que pueden alimentar
las tres postulaciones prioritarias. No es un paquete de envio y ningun archivo
de esta carpeta debe presentarse como version final sin una revision de
direccion.

## Convencion de lectura

- `01_` y `02_`: borradores narrativos y estructuras para transcripcion.
- `03_` a `06_`: lecturas de bases, investigacion, fichas y antecedentes.
- `ANEXOS/`: modelos y materiales auxiliares, no necesariamente firmados.
- `CODIGO_Y_DATOS/`, `CODIGO_Y_EVIDENCIA/` y `CODIGO_Y_OBRA/`: snapshots de
  implementaciones, pruebas, datos y piezas; sirven para auditar o producir
  evidencia, pero no son automaticamente anexos publicables.

## Procedencia

Los archivos se copiaron desde rutas existentes del repositorio y de la base de
investigacion. La fuente original no se mueve ni se reemplaza. Las bases PDF
originales verificadas siguen en
`/home/mak/BASES/postulaciones/`; la base de Ama Amoedo se mantiene como
incidencia documentada porque el enlace oficial consultado no entrega el PDF.

Cada subcarpeta contiene un README con el mapa de origen, los limites de uso y
las decisiones pendientes. El codigo copiado puede depender del arbol original
de MAK y no se considera un paquete ejecutable aislado.

## Gate antes de enviar

Confirmar en el portal de cada concurso: fecha y hora de cierre, identidad y
CV, titularidad de derechos, cartas firmadas, espacio de ejecucion,
presupuesto, enlaces publicos, formato de anexos y estado final del formulario.
Las cifras, resultados de codigo y antecedentes de obra deben conservar su
fuente y su fecha de medicion.
