# Borrador - Fondart Nacional Investigacion 2027

Proyecto: *Jardines interpretativos: publicos y trazabilidad de una lectura
visual*.

## Contenido

- `01_BORRADOR_POSTULACION_JARDINES.md`: borrador narrativo de la postulación.
- `02_BORRADOR_ESTRUCTURADO_JARDINES.json`: estructura para convertir el
  borrador al FUP.
- `03_LECTURA_DIRECTIVA_JARDINES.md`: encaje, criterios y alertas revisados.
- `04_INVESTIGACION_JARDINES_INTERPRETATIVOS.md`: modelo semantico, pipeline,
  correlaciones y limites de la investigación.
- `05_FICHA_CONVOCATORIA.json`: ficha operativa del concurso.
- `CODIGO_Y_DATOS/`: workflow de procedencia, reconciliacion, base SQLite y
  exportaciones CSV.
