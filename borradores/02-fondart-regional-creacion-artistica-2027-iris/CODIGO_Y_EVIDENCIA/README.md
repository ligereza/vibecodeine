# Codigo y evidencia - IRIS

Snapshot técnico reunido para sostener el expediente de *IRIS: Mesa de
Montaje*.

- `compile_portfolio_dossier.py` y `portfolio_dossier.py`: compilación y
  validación del dossier portable.
- `compile_contracurator.py` y `contracurator.py`: consumidor de la vista del
  archivo y construcción de la experiencia curatorial.
- `opportunity_fit.py`: evaluación determinista de encaje entre restricciones
  de una oportunidad y evidencia de práctica.
- `mak_plataforma_hub.py`: superficie del hub donde conviven las rutas del
  portafolio y `research-garden`.
- `test_*.py`: pruebas copiadas de las superficies IRIS, dossier, contracurator
  y opportunity fit.
- `archivo.json` y `campo.json`: snapshots de datos de proyección del archivo,
  no un portfolio público listo para adjuntar.

`/home/mak/iskvw/datos/` y `/home/mak/cultura/mak_plataforma/`. Los imports y
las rutas de ejecución siguen apuntando al repositorio original.
