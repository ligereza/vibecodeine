# Expediente IRIS — Fondart Regional 2027

Esta carpeta reúne los anexos de la postulación de **IRIS: Mesa de Montaje**.

- `FUP_IRIS_GENERADO.md`: salida reproducible del validador de bases.
- `ANEXO_01_DESCRIPCION_PROPUESTA.md`: descripción artística para adjuntar al

  las cartas oficiales del equipo declarado.
