## Tesis común

**Dimensiones del Orden** es un motor de ordenamiento visual-computacional para
archivos creativos heterogéneos. No promete que una máquina encuentre el orden
perfecto: construye ordenamientos parciales, reversibles y explicables para una
pregunta concreta, conservando fuente, contexto, incertidumbre y decisión
humana.

```text
archivo visual y contextual
  -> lectura de estructura y procedencia
  -> representación visual de relaciones, foco y desconocidos
  -> ordenamiento reversible según una pregunta
  -> decisión/corrección humana
  -> salida pública: herramienta, obra, taller o publicación
```

Las dimensiones posibles no son una única métrica: temporal, causal,
informacional, reconstructiva, computacional, espacial/topológica, de
autoridad y curatorial. Esto conecta arte, visión, computación y orden sin
atribuirle a la herramienta capacidades clínicas, psicológicas o de lectura de
personas.

## Qué existe y qué papel cumple

### IRIS / Portfolio Editor

Es el núcleo inmediato y más demostrable: una interfaz para recorrer, ordenar,
relacionar y editar un archivo/portafolio artístico. Su valor postulable no es
“automatizar la curaduría”, sino hacer visible el criterio de orden y permitir
que el artista lo corrija, lo revierta y lo convierta en una salida.

### WACHUMA

Es una rama de aplicación del mismo principio: jardín/atlas digital con
fuentes, relaciones, estados y reglas de interpretación. Tiene evidencia de
desarrollo local, pero exige más cuidado de procedencia, consentimiento,
conocimiento biocultural y publicación. Para una entrega urgente conviene
usarlo como caso de prueba o línea posterior, no como el centro de las tres
primeras postulaciones.

### FARMAKSIA / PUPILA / XANAX

Aporta una frontera importante: representación sensorial, analogías con
residuo explícito, propuestas reversibles y estado compartido metadata-only.
Es una buena arquitectura de extensiones, pero no conviene prometer ahora
coordinación multiusuario, captura de mirada, inferencia humana o un producto
comercial terminado.

### Grados de desacuerdo / Sin referencia

Es un antecedente de proyecto distinto, con una tesis fuerte sobre percepción
óptica y una obra web. No debe mezclarse automáticamente con IRIS: contiene
afirmaciones científicas y exigencias de seguridad, accesibilidad y respaldo
que requieren revisión propia.

## Cuarta opción, no prioritaria para la primera entrega

**Fondart Nacional — Investigación** es intelectualmente muy compatible si se
formula como estudio de campo sobre cómo artistas ordenan archivos, portafolios
y nuevas herramientas digitales, con transferencia pública. Tiene cierre el
14 de septiembre y tope de $15.000.000. Es más exigente metodológicamente y
no debe confundirse con una solicitud de desarrollo de producto.

**Fondo Audiovisual — Investigación** sólo conviene si el objeto real pasa a
ser el ecosistema audiovisual y se realiza trabajo de campo. **Obras
experimentales** exige una obra audiovisual terminada y un documento del
proceso. Ambas son posibles extensiones, pero no son la vía más simple para
IRIS como herramienta de portafolio.

## Líneas descartadas o diferidas

- Becas Chile Crea no financia este proyecto directamente: financia formación
  individual, perfeccionamiento o posgrado. Para la mayoría de las regiones el
  plazo ya pasó; además sólo permite una postulación por persona.
- Libro y Lectura exige una investigación genuina sobre el ecosistema del
  libro, lectura o bibliotecas; no corresponde forzar IRIS allí.
- Artes Escénicas exige objeto y campo propios de ese sector; no corresponde
  convertir una herramienta de portafolio en proyecto escénico por conveniencia.
- Ama Amoedo se mantiene como radar futuro: las bases públicas localizadas
  corresponden a ciclos anteriores y no constituyen una convocatoria abierta
  vigente verificable para esta entrega.

## Separación de las tres versiones

### 1. Obra/herramienta

Título de trabajo: **IRIS — Dimensiones del Orden: una herramienta visual para
artistas**.

Resultado: versión pública funcional, una experiencia/exhibición y una
documentación que muestre cómo el artista conserva la decisión sobre el orden.
WACHUMA puede aparecer como corpus demostrativo sólo si sus fuentes y permisos
están claros; no debe arrastrar el proyecto hacia un atlas biocultural no
resuelto.

### 2. Difusión

Título de trabajo: **IRIS abierto — archivo, portafolio y orden visual**.

Resultado: publicación accesible y portable de obras seleccionadas, con
recorridos, relaciones y mediación para públicos. Aquí el argumento central es
que IRIS ya existe como herramienta en desarrollo y ahora se transforma en una
superficie pública de acceso a obras, no en que se financiará una investigación
abstracta.

### 3. Formación

Título de trabajo: **Laboratorio Dimensiones del Orden: herramientas para
portafolios vivos**.

Resultado: taller/laboratorio gratuito para artistas y agentes culturales,
con corpus de ejercicios, guía transferible, sesiones documentadas y una
versión de IRIS que permita recorrer, seleccionar, relacionar, revisar y
revertir decisiones.

## Regla de sostenibilidad

La futura adaptación privada —por ejemplo PUPILA u otras ramas para
licitaciones— se describe como continuidad y sostenibilidad posterior, no como
el objetivo principal financiado. El proyecto cultural debe demostrar primero
valor para artistas, colegas y públicos, con límites, procedencia y decisión
humana visibles.
