# Estado de esta carpeta: todo aquí es BORRADOR SIN FIRMA

Ningún archivo de esta carpeta es un anexo listo. Ninguno está firmado, ninguno
fue enviado y ninguno recibió confirmación de nadie. Se marcan así para que no
puedan confundirse con documentos obtenidos.

| Archivo | Qué es | Qué le falta para ser anexo |
|---|---|---|
| `BORRADOR_INDICE_PORTFOLIO.md` | Índice de candidatas desde decisiones ya registradas del titular | Decisión del titular, epígrafes y armado del PDF |
| `BORRADOR_SOLICITUD_ESPACIO.md` | Texto para pedir compromiso o cotización de espacio | Enviarlo, recibir respuesta y firma de un tercero |
| `BORRADOR_CARTA_ASISTENTES.md` | Texto para el compromiso de asistencia de Formativas | Quince firmas individuales |
| `BORRADOR_CONSULTA_SIAC.md` | Pregunta redactada para el canal oficial | Que el titular decida enviarla |

**En la variante recomendada, ninguno de estos borradores bloquea un envío.**
El Expediente 1 (Ama Amoedo) y el Expediente 2 (Difusión) no requieren la firma
de ningún tercero. Sólo el Expediente 3 (Formativas) y la alternativa Creación
dependen de algo de esta carpeta.
